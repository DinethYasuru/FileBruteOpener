# Optional local helpers (detection only - generation and inspection)

The browser app needs nothing beyond `index.html` for its PDF/ZIP identification and
password-recovery features. This folder holds two small, **optional** Node/Python scripts
for people who also have the relevant tools installed locally and want to work with the
formats the browser app can only detect, not verify passwords against (RAR, 7z, Office Open
XML, GPG — see the capability matrix in the main README).

Neither script attempts to crack or test passwords.

## Generating sample encrypted files

`generate-samples.js` creates real encrypted RAR/7z/Office/GPG files for a password you
choose, so you can see the browser app's detection work against genuine files (the same idea
as the in-browser generator for PDF/ZIP, just for formats that need their actual real-world
encoder rather than something reimplementable in pure JS):

```
node local-service/generate-samples.js /path/to/output/dir mypassword
```

Each format is generated by shelling out to its real tool, and every output file was
independently validated against a *different* tool than the one that made it:

| Format | Created with | Validated with |
|---|---|---|
| `.gpg` (AES-256 symmetric) | `gpg --symmetric` | `gpg --list-packets` |
| `.7z` (AES-256, encrypted header) | `7z a -mhe=on` | `7z l` (wrong-password rejection) |
| `.rar` (AES-256, encrypted header) | `rar a -hp` | `unrar` / `7z l` (wrong-password rejection) |
| `.docx`/`.xlsx`/`.pptx` (Agile encryption) | LibreOffice headless (`office_encrypt.py`, via UNO) | `msoffcrypto-tool` (correct password decrypts, wrong password is rejected) |

Any tool that isn't installed is skipped (reported, not fatal) rather than failing the whole
run. Needs whichever of `gpg`, `7z` (the `7zip`/`p7zip-full` package), `rar` (proprietary;
package `rar`, in the `multiverse`/`universe` repo), or `soffice` + `python3-uno`
(LibreOffice headless automation) you want samples for.

## Inspecting a file

```
node local-service/inspect.js /path/to/file.rar
node local-service/inspect.js /path/to/file.7z
node local-service/inspect.js /path/to/file.gpg
```

Shells out to each tool's own listing/inspection command, which is enough to confirm
encryption is present and, for archives, list member names — without ever supplying a real
password. Requires the corresponding CLI tool (`7z`, `unrar`, or `gpg`) to already be
installed and on `PATH`; if it isn't, the script says so and exits.
